# 🎲 EMÜ322 - Stochastic Random Variate Simulator

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://onurfgg.github.io/stochastic-variate-simulator/) 
[![Course](https://img.shields.io/badge/Course-EMÜ322-blue.svg)](#)

A web-based interactive simulation tool developed for the **EMÜ322 Simulation Modeling and Analysis** course (Spring 2026). This project serves as a Decision Support System (DSS) to generate and analyze random variates, dynamically comparing empirical sample distributions with their theoretical counterparts.

## 🚀 Live Demo
**[Click here to run the simulation directly in your browser!](https://onurfgg.github.io/stochastic-variate-simulator/)**  

## ⚙️ Implemented Methods
This simulator successfully evaluates mathematical models and implements the following random variate generation algorithms:
1. **Composition Method:** For a specific piecewise exponential probability density function.
2. **Acceptance-Rejection Method:** For a Triangular distribution, including empirical vs. theoretical acceptance rate calculations.
3. **Convolution Method:** For a Binomial random variable.
4. **Inverse Transform Method:** For a Continuous Uniform distribution.

## 📊 Key Features
- **Real-time Generation:** Generates sample sizes (N=500) instantly using stochastic principles.
- **Statistical Analysis:** Automatically calculates and compares Sample Mean & Variance with Theoretical Mean & Variance.
- **Interactive Data Visualization:** Utilizes **Chart.js** to plot empirical histograms against theoretical Probability Density Functions (PDF) or Probability Mass Functions (PMF).
- **Export Capabilities:** One-click feature to download the generated distribution charts as PNG for academic reporting.
